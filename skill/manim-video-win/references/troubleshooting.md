# うまくいかないとき

まず `build.cmd doctor` を実行し、NG の項目と → の案内を見る。

## セットアップ

| 症状 | 対処 |
|---|---|
| 「Windows によって PC が保護されました」と出る | 「詳細情報」→「実行」。ダウンロードした ZIP は、右クリック →「プロパティ」→「許可する」にチェックしてから展開すると出にくい |
| ダウンロードに失敗する | 社内ネットワークで GitHub・astral.sh・pypi.org・api.aivis-project.com への接続が止められていないか、情報システム担当に確認する（README の「社内で配布する前に」） |
| 途中で止まった | もう一度 `setup.bat` を実行する（入っているものは飛ばす） |
| PowerShell スクリプトが実行できない | 組織のポリシーで止められている。情報システム担当に `setup.ps1` の実行を相談する |

## Codex から実行したとき

- 承認を求められる: `build.cmd` は (1) uv で Python を動かす (2) AivisSpeech エンジンを起動する (3) 127.0.0.1:10101 に接続する (4) `tools.json` の `root` のフォルダを読む。どれも動画づくりに必要なので許可する。
- サンドボックスの中で AivisSpeech エンジンが起動できない／すぐ止まる: 一度だけ `setup.bat` のあとに出てくる診断（または PowerShell で `build.cmd voices`）を自分で実行してエンジンを立ち上げておくと、以後は動いているエンジンにつなぐだけになる。PC を再起動したら同じことをする。
- コマンドの出力が文字化けする: 実害はない。気になる場合は Codex に「出力は要点だけ日本語で教えて」と頼む。

## 描画

| 症状 | 対処 |
|---|---|
| `MathTex` が `LaTeX compilation error` | フォルダのパスに日本語やスペースが無いか確認。パッケージ不足ならログに出る名前を `<root>\TinyTeX\bin\windows\tlmgr.bat install <名前>` |
| 日本語が □ になる | `jtext()` を使う。フォントを変えるなら環境変数 `MANIM_VIDEO_FONT`（例: `BIZ UDPGothic`） |
| PC が重い・メモリ不足で落ちる | `-j 1` で 1 シーンずつ描く。`-q m`（720p）に下げる |
| 音声がずれる | `manim` を直接実行していないか。必ず `build.cmd` を通す |

## 音声

| 症状 | 対処 |
|---|---|
| 声 'xxx' が見つかりません | `build.cmd voices` で正しい名前を確認する（話者名/スタイル名） |
| 初回の合成がとても遅い | AivisSpeech は CPU で動くので、初回のモデル読み込みに時間がかかる。2 回目からはキャッシュ（`build\audio\cache`）を使う |
| AivisSpeech が起動しない | ログ `<root>\logs\aivisspeech-engine.log` を見る。ポート 10101 を他のアプリが使っていないか |
| とりあえず音声を付けたい | `--engine sapi`（Windows 標準音声）。日本語の声が無い場合は Windows の設定 → 時刻と言語 → 音声 で日本語を追加 |
